# Scratchpad: Quick Investigations

**Scratchpad** is a collection of short musings, code snippets and "what-if" experiments. 

Think of it as an advanced form of "I should Google that".

This isn't a portfolio of polished projects, but rather a sandbox for spontaneous questions, quick tests and creative tinkering.

---

## What's Inside?

- **Short code snippets** and mini "projects"  
- **Quick analyses** and exploratory data work  
- **Musings** on algorithms, tools and curiosities  

A digital notebook for ideas and mental "doodles" that are too brief or experimental to warrant a full project, but still interesting enough to invest some time into.
